# Mini_Project_1_Anggitha-Christien-Wulandari

Nama : Anggitha Christien Wulandari

NIM : 2609116036

Penjelasan Program

Program yang dibuat adalah Sistem Pendataan Pengunjung Perpustakaan. Program ini digunakan untuk menyimpan dan mengelola data pengunjung perpustakaan. Data yang disimpan terdiri dari nama, NIM, prodi, dan keperluan.
Program menggunakan list bernama data_pengunjung sebagai tempat penyimpanan data sementara. Setiap data pengunjung disimpan dalam bentuk tuple.

Program memiliki 5 pilihan menu, yaitu:

1. Tambah Data
digunakan untuk memasukkan data pengunjung baru berupa nama, NIM, prodi, dan keperluan.
2. Lihat Data
digunakan untuk menampilkan seluruh data pengunjung yang sudah tersimpan. Jika belum ada data, program akan menampilkan pesan bahwa belum ada data.
3. Ubah Data
digunakan untuk mengubah data pengunjung berdasarkan NIM. Jika NIM tidak ditemukan, program akan meminta pengguna memasukkan NIM kembali.
4. Hapus Data
digunakan untuk menghapus data pengunjung berdasarkan NIM. Jika NIM tidak ditemukan, pengguna akan diminta memasukkan NIM kembali.
5. Keluar
digunakan untuk mengakhiri program.

Program menggunakan perulangan while agar menu terus ditampilkan sampai pengguna memilih menu keluar. Program juga menggunakan percabangan if, elif, dan else untuk menentukan proses berdasarkan pilihan pengguna serta melakukan pengecekan data.
Kesimpulannya, program ini dibuat untuk mempermudah pendataan pengunjung perpustakaan dengan proses tambah, lihat, ubah, dan hapus data yang sederhana.
